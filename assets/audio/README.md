# AMIGOS RUN — Diretório de Assets de Áudio

Este diretório armazena os arquivos de áudio locais do jogo.
O sistema **AudioManager** carrega automaticamente estes arquivos se estiverem presentes.
Se os arquivos `.mp3` ou `.wav` não estiverem presentes nesta pasta, o jogo utiliza automaticamente a **síntese procedural Web Audio API**, garantindo 100% de funcionamento offline e sem quebrar.
